# gnDoc 通信の方針

gnDoc（`gnDoc.exe`）と描画ライブラリ gnDocRd が、**いつ・どこへ・何を送るか**をまとめたものです。対象は gnDoc v0.4.3 です。

> [!NOTE]
> **gnDoc はオフラインで動きます。** 文書を開く・書く・描く・印刷する・HTML や PDF に書き出す、のどれも通信しません。
> 通信するのは、**下の表の機能を使ったときだけ**です。利用の統計・識別子・使った回数は、どこへも送りません。

---

## 1. 通信する機能の一覧

| # | 機能 | 通信するとき | 送る物 | 行き先 | 止め方 |
| :---: | --- | --- | --- | --- | --- |
| 1 | 図の外部描画（`plantuml` / `dbml` / `d2` / `graphviz`） | 文書にこの4つの記法があり、それを描くとき | **図のソースコード** | `kroki.io`（既定） | 設定 →「連携」で送り先を自分のサーバーに変える／この4つの記法を使わない |
| 2 | 文書の中の外の画像 | 画像の場所が `http://`・`https://` のとき、描くと取りに行く | 画像の URL（取得の要求） | その画像のサーバー | 画像を文書と同じフォルダに置く |
| 3 | ライブラリの生成（🦉 LibGen） | 「生成」を押したとき | 取得の要求だけ | `cdn.jsdelivr.net`・`cdnjs.cloudflare.com` | 生成は初回の一度だけ。その後は通信しない |
| 4 | ライブラリの新しい版のお知らせ | 生成の後 | 部品の名前（版の問い合わせ） | `registry.npmjs.org` | 生成しなければ問い合わせない |
| 5 | ☁ Azure の声で読み上げ | 設定で ☁ を選び、ご自身の Azure のキーを入れたときだけ | **読み上げる文** | `<地域>.tts.speech.microsoft.com`（ご自身の Azure） | ☁ を使わない |
| 6 | 🌐 WebView2 の声で読み上げ | 名前に「Online」と付く声を選んだとき | **読み上げる文** | Microsoft | 名前に「Online」の無い声（💻 Windows の声など）を選ぶ |
| 7 | 🎙 音声入力 | 🎙 を押して話すとき（初回に確かめます） | **話した声** | ☁ ご自身の Azure（部品は `cdn.jsdelivr.net` から読む）／🌐 Microsoft | 🎙 を使わない |
| 8 | 📝 議事録のまとめ | ☁ でまとめを押したとき | **まとめる文** | ご自身の Azure（Language） | 押さない |
| 9 | 試し場で開く | 図やコードの「…で開く」を押したとき | **その図・コード** | `mermaid.live`・`jsfiddle.net`・`replit.com`・`godbolt.org`・`play.rust-lang.org`・`go.dev`・`play.d2lang.com`・`dbdiagram.io`・`app.diagrams.net` など | 押さない |
| 10 | リンク・簡易ブラウザ | リンクを押したとき・簡易ブラウザで開いたとき | 普通のブラウザと同じ | 開いたページ | 押さない |
| 11 | 🆕 新しい版の確かめ（exe） | 起動の後に**1日1回だけ**・⚙️ の 🔍 を押したとき | **何も送らない**（取得の要求だけ） | `raw.githubusercontent.com`（公式リポジトリの `latest.json`） | ⚙️ →「全般」の 🆕 を外す（§4） |
| 12 | 新しい版の exe を落とす（exe） | 知らせの［更新］を押したとき | **何も送らない**（取得の要求だけ） | `github.com`（公式リポジトリの Release） | 押さない |

> [!WARNING]
> **1 の図の外部描画は、既定で `kroki.io` へ図のソースを送ります。** 外へ出せない内容を図にするときは、設定 →「連携」で送り先を社内などのサーバーに変えるか、`mermaid` / `flow` など同梱の記法（オフライン）で描いてください。

> [!IMPORTANT]
> **5〜8 は、文の中身や声を外へ送ります。** ☁ の声は、本文に「社外秘」「部外秘」「confidential」などがあると、読み始める前に確かめます。音声入力は、初めて使うときに確かめます。

---

## 2. 送らない物

- **利用の統計**（起動の回数・使った機能・時間）。集める仕組みがありません
- **識別子**（端末・利用者を見分ける番号）。作っていません
- **文書の中身**。上の表の機能を使ったとき以外は、どこへも送りません
- **Azure のキー**。この PC の gnDoc の設定の中にだけ置きます。設定の書き出し（📤）にも入りません

---

## 3. 描画ライブラリ gnDocRd

gnDocRd（`gnDocRd.js`）は、**組み込んだページで自分からは通信しません。**

| 通信するとき | 中身 |
| --- | --- |
| `gnDocRd.configure` で外部描画の送り先を設定したとき | 1 と同じ4つの記法を描くと、その送り先へ図のソースを送る。**既定は送り先なし（送らない）** |
| `gnDocRdLibGen.html` で「生成」を押したとき | 3・4 と同じ |
| `gnDocRd.checkUpdate()` を呼んだとき（見本の「🆕 新しい版を確かめる」） | 公式リポジトリの `latest.json` を読むだけ（Cookie・リファラーは送らない）。**呼ばなければ通信しない** |
| 文書の中の外の画像 | 2 と同じ |

---

## 4. 新しい版の確かめ

`gnDoc.exe` は、新しい版が出たことを次の作りで知らせます。

- 起動の後に**1日1回だけ**、公式リポジトリの `latest.json`（版の番号と exe の URL・大きさ・SHA-256 が書いてある小さなファイル）を読みます。行き先はプログラムに書き込んであり、変えられません
- **受け取るだけで、何も送りません**: 要求に版・OS・識別子・Cookie・どこから来たか（リファラー）を載せません。名前は固定の `gnDoc` です
- 読めなかったとき（オフライン・社内の中継サーバー・形の違う応答）は、**黙ってあきらめます**。起動を待たせることも、エラーを出すこともありません
- 新しい版があると、下端のバーに「🆕 v… があります ［更新］［変更点］［飛ばす］」が出ます。**勝手に入れ替えません**
- ［更新］を押したときだけ、新しい exe を**同じフォルダ**へ落とし、大きさと SHA-256 が `latest.json` と合うことを確かめてから入れ替え、開いていた文書を引き継いで起ち直します。合わなければ使わず、新しい版が起ち上がらなければ元の版に戻します。exe のフォルダに書けないとき（`Program Files` など）は、Release のページを開くだけです
- **止め方**: ⚙️ →「全般」の 🆕 を外すと、**一度も通信しません**。🔍 を押すと、その場で確かめます
- 避けられない物: GitHub には、接続元の IP アドレスと時刻が残ります。exe を落とすと、GitHub が落とされた回数を数えます（gnDoc が送る物ではありません。`latest.json` を読むだけでは数えられません）

> [!NOTE]
> SHA-256 で防げるのは、壊れた・途中で切れた exe です。公式リポジトリそのものが乗っ取られたときは防げません（防ぐにはコード署名が要り、今は付けていません）。

---

## 5. まったく通信しないで使うには

1. 🦉 LibGen でライブラリを作った後は、ネットにつながなくても全部の描画が使えます（4つの外部描画の記法を除く）
2. `plantuml` / `dbml` / `d2` / `graphviz` を使わない（または送り先を手元のサーバーにする）
3. 読み上げは 💻 Windows の声か、名前に「Online」の無い声を選ぶ。☁ を使わない
4. 🎙 音声入力・📝 まとめ・試し場で開く・簡易ブラウザを使わない
5. ⚙️ →「全般」の 🆕（新しい版の確かめ）を外す
6. 画像は文書と同じフォルダに置く
